## Part 5: PR description (paste into GitHub)

Title: `M5: agent makes one tool call through MCP, with cost ledger, budget gate and tracing`

```markdown
## What

Brief step 5a: a basic agent that connects to the MCP server as a client and makes one tool
call based on a hardcoded request. The ReAct loop comes in M6, on top of this.

- `agent/costs.py`: price table lookup, cost per call, ledger total and the budget gate
  ($4.00 hard stop, WARN from $3.00).
- `tracing.py`: OpenTelemetry spans written to `traces/<request_id>.jsonl`; every log line
  now carries `trace_id` and `span_id`.
- `agent/llm.py`: the single wrapper every paid model call goes through. It writes one line
  to `logs/cost_ledger.jsonl` and one `llm.call` span per call.
- `agent/mcp_bridge.py`: turns the server's MCP tool list into Claude tool definitions and
  calls tools with `request_id` and `traceparent` in the request metadata.
- `agent/single_call.py` and `scripts/agent_once.py`: the hardcoded-request run
  (`make agent-once`).
- `cost_report.py`: spend by env, stage and request (`make cost-report`).

## Why

- This is the first milestone that spends money, so cost tracking and the budget gate land
  before the first live call, not after it.
- One wrapper for all model calls means no call can skip the ledger or the trace.
- The budget gate runs before the Anthropic client is created. The $1 gap below the $5
  limit absorbs any error in our own price table.
- `tool_choice` is `auto`, because forced tool choice returns a 400 on Sonnet 5.5 and the
  same code must run on Haiku (dev) and Sonnet (eval).
- The tracer provider is created per run, not set globally, so tests stay independent.
- Spans and logs record the tool's result status and `data_version`, never the full result,
  because `get_employee_info` returns the employee's name.

## How it was built

TDD in four red/green steps (see the commit list). Each red commit holds only failing tests.

## Testing

- Unit: cost maths (incl. cache tokens and Haiku long-prompt pricing), ledger parsing,
  budget thresholds, span export and parent links, log correlation, the LLM wrapper with a
  fake client (ledger line, span, no ledger line on failure), MCP bridge, cost report.
- Integration: fake LLM plus the real in-process MCP server; the server's real verdict comes
  back and the trace links `agent.run`, `llm.call` and the tool span.
- CI never calls the real Claude API.
- Live (manual, Haiku): one run of `make agent-once`; cost line and trace file produced.
  Cost: $_____ (from `make cost-report`).

## Next

M6: the full ReAct loop, the `final_answer` schema, the step cap and the C1 to C7 guards.
```
